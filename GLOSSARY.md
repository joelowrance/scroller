# Scroller

An 80s-arcade mashup: a sequence of original games, each in a classic arcade genre, played as one continuous arcade run.

## Language

**Cabinet**:
One of the mashup's original games, in a single classic arcade genre, made up of two Stages.
_Avoid_: Game, mini-game, world

**Stage**:
One of the two playable sections of a Cabinet.
_Avoid_: Level

**Cabinet Transition**:
The showpiece sequence that plays between one Cabinet and the next.
_Avoid_: Level transition, cutscene

**Stage Card**:
The brief interstitial between a Cabinet's two Stages.
_Avoid_: Loading screen, Stage transition

**Power-up**:
A pickup that improves the Hero's abilities for the rest of the current Cabinet.
_Avoid_: Upgrade, item, buff

**Practice**:
Playing a single previously cleared Cabinet outside a Run; it never touches the Save or the High Score Table.
_Avoid_: Replay, free play, level select

**Hero**:
The single character the player controls through every Cabinet of a Run, whether piloting a ship or on foot.
_Avoid_: Player (that's the human), protagonist, character

**Restart Point**:
A place within a Stage where the Hero reappears after losing a life (but not the last one).
_Avoid_: Checkpoint, respawn

**Run**:
One playthrough of the Cabinets, starting from the first.
_Avoid_: Playthrough, session, campaign

**Ending**:
The "you finished" sequence shown when a Run clears the final Cabinet; it ends the Run.
_Avoid_: Win screen, finale, credits

**Game Over**:
The end of a Run, reached by losing the last life; a Run that reaches Game Over can never be resumed.
_Avoid_: Death, fail

**High Score Table**:
The local top-ten list of Run scores, each tagged with three initials.
_Avoid_: Leaderboard, rankings

**Attract Mode**:
The self-running title loop shown when nobody is playing, including the High Score Table.
_Avoid_: Demo, idle screen

**Save**:
The record of an unfinished Run, written each time a Stage is cleared and used up as soon as the next Stage begins; it only exists between Stages.
_Avoid_: Checkpoint, savegame, suspend
